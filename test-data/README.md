# Fictional onboarding test packs

All names and profiles in these folders are fictional. They contain no real contact information.

Each pack includes:
- `profile.json` for the name, job position and organization fields
- `job-description.txt`
- `cv.txt`
- `application-letter.txt`
- `study-notes.md`

The same three packs are available through **Load fictional sample data** on the first KaziCoach screen. To test manual uploads, paste the profile values and upload each corresponding file to its field. Delete the workspace from Settings before testing the next profile.
